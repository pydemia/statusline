# Statusline Support

For bugs, compatibility problems, or feature requests, open an issue at:

https://github.com/pydemia/statusline/issues

When reporting a page-layout problem, include:

- browser name and version;
- Statusline version;
- the affected URL when it can be shared;
- whether **Dock below page content** is enabled;
- a screenshot showing the problem;
- concise reproduction steps.

Do not include passwords, authentication cookies, access tokens, or other
credentials in issues.
